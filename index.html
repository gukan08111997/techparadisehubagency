Common questions

Read all FAQs

Do I need a technical background?

No. Programs such as Python Coding Foundations, the Data Analytics Starter Program and the Python Code Starter crash course start from the basics. Our course options suit different experience levels, from students and freshers to working professionals.

Can I try a class before I enroll?

Yes. Book a free demo class from the contact page or the “Let's talk” button and we will confirm a slot by email.

Which course should I start with?

If you are new to tech, start with Python Coding Foundations, Excel Mastery Lab or the Data Analytics Starter Program. For an analyst role, Data Analytics covers Excel, SQL, Python, Power BI and Tableau. Interested in AI, marketing or web development? Look at Generative AI, Digital Marketing, Full Stack or MERN Stack Development. Tell us your goal and we will suggest a path.

What is the difference between a career course, a one-month program and a crash course?

Career courses cover a field in depth and end with a portfolio project. One-month core programs focus on one tool or skill, such as Power BI, Tableau, SQL, Excel or Python. Crash courses cover the essentials of a subject in five days.

Can I take a crash course first and a longer course later?

Yes. Many learners start with a crash course to test the subject, then continue with a one-month program or a career course. Ask us about upcoming batches.
